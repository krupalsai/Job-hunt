# Learn for: TCS — Mass Hiring (fresher roles)

## What this job actually is

TCS hires thousands of freshers at once. The post says it is "easy to crack
as a fresher". What that really means: the test checks school-level basics,
not deep coding. But thousands of people apply — so your basics have to be
genuinely solid, not just watched in a video.

## The honest starting point

You already do something most freshers can't: you run a live system with real
users. You know what a web app, a database and a deployment are — from the
operator's seat, because you integrated and debugged them yourself. What's
missing is the code underneath: writing programs yourself, from scratch.
That's what this plan builds, simplest first. Give yourself 8–12 weeks of
daily practice. One hour a day beats seven hours on Sunday.

## Learn in this order (simplest first)

### 1. What a program even is (week 1)

- You already operate programs every day — now you're learning to write them.
  A program is just a list of instructions the computer follows, one by one,
  like a recipe.
- You do NOT need to install anything. On your phone browser, open
  **programiz.com/python** — it runs Python code for free, no setup.
- Your first win: make the computer print your name. That is a real program.
  Everything else is a longer version of this.

### 2. Python basics — the only language you need right now (weeks 2–4)

- **print** — show something on screen.
- **variables** — a named box that holds a value. `name = "Krupal"` puts the
  word Krupal in a box called name.
- **input** — ask the person using the program to type something.
- **if / else** — the program makes a decision: "if marks are above 40, print
  pass, else print fail".
- **loops** — repeat something: "print the numbers 1 to 10" without writing
  ten lines.
- How to learn each one: read it once, then TYPE the example yourself
  (don't copy-paste), then change it and break it on purpose. Breaking things
  is how you actually learn.

### 3. Small problems — thinking in steps (weeks 4–6)

- Check if a number is even or odd. Find the biggest of three numbers. Print
  a triangle of stars. Count how many digits are in a number.
- These feel silly. They are almost exactly the kind of questions fresher
  coding tests ask.

### 4. Aptitude — the written test (30 minutes daily, alongside everything)

- This is school maths with a timer: percentages, ratios, averages,
  time-speed-distance, number series.
- Honest truth: most freshers fail here only because they never practised
  with a stopwatch. Practise timed, on paper.

### 5. Databases — what SQL is (weeks 6–8)

- A database is like a super-powered Excel sheet that apps use to remember
  things (your student data lives in one).
- **SELECT** means "show me the rows". **WHERE** means "only the rows that
  match". That's 80% of what fresher interviews ask.
- Practise free in your browser on **sqlbolt.com**.

### 6. Your project story — your biggest advantage (week 8+)

- You integrated, deployed and operate a REAL website with REAL users —
  payments, database, bots. Almost no fresher applying can say that.
- Learn to say in 60 seconds: what the site does, what you wired together
  yourself, one live problem you debugged.
- Say it to your phone camera. Watch it back. Fix the rambling parts. Do it
  three times.

## How you'll know you're ready

- You can write a small Python program without looking at notes.
- You can solve 8 out of 10 easy practice problems on your own.
- You can explain what your website does in 60 seconds, out loud.

## What NOT to worry about yet

Big scary topics — data structures, algorithms, system design. TCS fresher
rounds rarely go there. Deep basics beat shallow everything.
