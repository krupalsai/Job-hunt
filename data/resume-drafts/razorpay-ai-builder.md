## What I Built From Zero

**Founder & Operator — Student Platform**
*Live in production | 2026 – Present — 150+ real users, 2 colleges, registered business*

- **The problem:** students across two colleges were stuck on certificate, document and fee flows tied to a High Court case — no single place tracked their case, their fees, or their documents. I found it by talking to the students, and the metric that moved is simple: 150+ students now register, pay, and track their cases on the platform instead of chasing it manually.
- **Shipped AI-first, in days, with AI tools:** full-stack platform built with AI-assisted coding — 152 RESTful API routes (auth, payments, notifications), relational schema with 100+ production migrations, Git-based deployments on Vercel.
- **Got it adopted:** onboarded 150+ students across 2 colleges; 1,300+ real support messages handled; the support bot answers from each student's own records with human escalation instead of invented answers; hearing alerts keep students informed without them asking.
- **Payments:** Razorpay live — order creation, checkout, HMAC-verified webhook → idempotent approval; the app charges one total fee of Rs 2,200 and accepts automated gateway verification only (manual screenshot approvals refused by design); Cashfree and PhonePe integrations wired behind gateway switching.
- **AI in production:** in-app AI voice support agent — WebRTC media server on an Oracle Cloud Linux VM with an HMAC-signed negotiation endpoint; browser mic audio → speech-to-text (Groq Whisper) → answer engine → Telugu text-to-speech (Piper), verified end to end; RAG assistant (LangChain + ChromaDB + local sentence-transformer embeddings) answering help questions from a hand-written corpus, with a similarity threshold that rejects off-topic questions instead of inventing answers.
- **Owns outcomes:** sole founder-operator — integration, deployment, live verification, daily operations, production incident triage (e.g. diagnosed a systemd crash-loop by tracing service logs to a missing environment file; restored an admin students list broken by an ambiguous database relationship, verified across all admin roles).
