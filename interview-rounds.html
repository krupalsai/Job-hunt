Applied 1 Nov · Referral accepted · Cloud AI Engineer

Google — Cloud AI Engineer

The loop: recruiter screen → technical phone screen → onsite of 4–5 rounds → hiring committee decides. About 3–5 weeks once it starts. At least one round is now in person (2026 change).

The 5 question types

  • Coding — Python. Arrays, strings, hashmap, trees, graphs. Solved with no AI help. Explain your thinking, write the code, test it.
  • ML system design — “Design an end-to-end ML system on Google Cloud”: where data lives, how the model trains, how it answers fast, how you watch it in production. They score tradeoffs, not buzzwords.
  • GenAI depth — transformers, RAG, embeddings, fine-tuning, evaluation, agents. Your strongest round.
  • Behavioral (Googleyness) — leadership, ambiguity, teamwork. Now includes technical grilling on your own past work.
  • AI fluency (new 2026) — read and fix existing code with Gemini beside you. Judged on how you prompt, how you check its output, and how you catch its mistakes.
Skills checklist — tick as each becomes explainable
  • Python fluency: variables, loops, functions, dictionaries, classes
  • DSA: arrays, strings, hashmap, trees, graphs, basic DP
  • RAG end to end: chunking → embeddings → vector search → rerank → answer with citations
  • Fine-tuning: what LoRA changes, when RAG beats fine-tuning, overfitting, eval metrics
  • LLM basics: tokens, context window, temperature, structured output, cost per request
  • Agents: when an agent beats a fixed chain; tools; human-in-the-loop
  • ML system design vocabulary: data pipeline → training → serving → monitoring
  • Google Cloud names (learn the words, be honest you have not used them): Vertex AI = train/host models, BigQuery = data warehouse
  • Two-minute explanations: your RAG assistant, your fine-tune, one failure story
Your starting point

GenAI depth first — it is your home ground and worth big marks. Coding runs daily in parallel; it is about 40% of prep for successful candidates.

Applied 22 Oct · SDE-I 10453457 · OA watch active

Amazon — SDE-I

The loop: online assessment → loop of 3–4 one-hour interviews, often back to back in one day → decision. About 4–8 weeks. Silence between rounds is normal, not a rejection.

Online assessment (HackerRank, 2026 format)

  • 1–2 DSA problems (arrays, sliding window, graphs are common)
  • Repo task with an AI assistant (new 2026) — you get existing code plus an AI helper: read it, fix bugs, add a feature. Practice working with AI, not just solo coding.
  • Work simulation — real work scenarios, now weighed more heavily as a behavioral filter
  • Work style survey — answer as the principles describe, not as you wish work was

The loop

  • Coding #1 and #2 — DSA, second one harder. Verbalize time/space complexity.
  • Object-oriented design — small design (e.g. a parking lot, a URL shortener): classes, how they talk, what breaks at scale.
  • Bar Raiser — hardest round. An interviewer from outside the team with veto power. Deep Leadership Principle grilling.
  • Every round has ~2 Leadership Principle questions. Coding skill alone does not clear the bar.
2026 changes to know
  • AI-assisted OA (above) — 2026 candidates confirm it
  • Bar Raiser now pushes for one cross-team conflict story and one project-failure-with-recovery story
  • GenAI fluency is appearing — one 2026 loop had a hiring-manager round mixing DSA, GenAI, and project discussion
  • Some loops back in person; most still virtual
Skills checklist
  • DSA mediums: arrays, strings, hashing, trees, graphs, DP basics — at 80%+ accuracy
  • OOP design: classes, interfaces, one small system designed cleanly
  • 16 Leadership Principles as stories, STAR format: Ownership, Dive Deep, Bias for Action, Customer Obsession first
  • Two anchor stories ready: PhonePe block (failure → recovery) and fake-receipt fraud (dive deep)
  • Repo-task practice: take one of your own old files, find a bug in it with AI help, explain the fix
Your starting point

Leadership Principle stories first — they decide more Amazon outcomes than one more DSA problem. Your PhonePe and fraud stories are already Bar-Raiser-grade raw material.

Oracle Health ASE1 applied 30 Oct · Referral asks out

Oracle — Associate Software Engineer

The loop: recruiter screen → HackerRank online assessment → 1–2 technical phone screens → virtual onsite of 3–5 rounds → reference checks → offer. Slow: 5–14 weeks total is normal.

  • OA: aptitude + OOP/OS/DBMS multiple-choice, plus 2–3 coding problems
  • Phone screens: LeetCode-medium DSA with tradeoff discussion (Java preferred, not required)
  • Onsite: coding, system design with enterprise-reliability framing (backups, SLAs, correctness), behavioral with an integrity focus, hiring-manager chat
Skills checklist
  • DSA mediums (same shared set as Amazon)
  • CS fundamentals in plain words: OOP (classes, inheritance), OS (process vs thread), DBMS (keys, joins, indexes), networking (what happens on a request)
  • SQL: SELECT, JOIN, GROUP BY — write 20 practice queries
  • Aptitude speed: percentages, ratios, time/work — overlaps your SI quant
  • 6–8 STAR stories including one ethics or difficult-stakeholder example
Your starting point

CS fundamentals + SQL. Oracle weights “does this person understand how computers actually work” more than the other loops. Your SI quant already covers the aptitude half.

Applied 4 Oct · AI/ML Computational Science Associate · Awaiting test invite

Accenture — AI/ML Associate

The loop: online assessment → technical interview → HR. The most fresher-friendly loop on this page — moderate difficulty, speed matters.

  • Online assessment (60–90 min): cognitive (aptitude, logical, verbal) + technical MCQ (OOP, DBMS, OS, DSA theory) + 1–2 Python coding problems, easy to medium
  • Technical interview: Python fundamentals, OOP, SQL, DSA basics, your projects, basic AI/ML concepts (what is ML, overfitting, what an LLM does)
  • HR: communication, shifts, joining, cultural fit
Skills checklist
  • Python basics solid: loops, functions, dicts, classes, file/JSON handling
  • OOP vocabulary: class, object, inheritance, polymorphism — one-line definitions
  • SQL basics: SELECT, WHERE, JOIN
  • AI/ML concepts in plain words: training vs using a model, overfitting, embeddings, RAG
  • Your project story: 2 minutes on the Student Platform + 1 minute on the RAG assistant
  • Aptitude practice — same material as SI quant
Your starting point

Python + OOP definitions + your project story. The test invite can land any day — these three are the highest marks per hour.

Applied 16 Oct · Apprentice, Enterprise Technology Services

AmEx — Apprentice (Technology)

The loop: resume screening → online assessment → technical interview → managerial/HR. Practical and predictable.

  • OA: ~3 coding problems, easy to medium (arrays, strings, basic DSA) + aptitude, 60–90 min
  • Technical: OOP concepts, Python or Java fundamentals, basic DBMS, your academic/personal projects
  • HR: behavioral questions aligned to AmEx “Blue Box Values”: integrity, customer-first thinking, continuous improvement
Skills checklist
  • Easy–medium DSA: arrays, strings, hashmap — solve cleanly, explain simply
  • OOP + DBMS one-line definitions (shared with Accenture prep)
  • Three short stories: one honest mistake, one customer helped, one thing you improved
Your starting point

Covered by the same foundation as Accenture. No separate track needed — one foundation, two loops.

Foundation first — the zero-base ladder

Every loop above stands on the same base. This is the order the industry itself recommends for AI engineering in 2026 — and it is honest about where you stand:

  • 1. Python — the non-negotiable. Named in 59% of AI-engineer job posts. Variables → loops → functions → dictionaries → classes.
  • 2. DSA — arrays → strings → hashmap → trees → graphs → DP basics. One pattern at a time.
  • 3. OOP + SQL — classes/objects/inheritance; SELECT/JOIN/GROUP BY. Oracle, Accenture, and AmEx all ask.
  • 4. LLM APIs + structured output — “the first skill interviewers test is reliable structured output”: tokens, context window, temperature, retries, cost.
  • 5. RAG — embeddings → vector DB → chunking → retrieval → citations. You have already built this.
  • 6. Agents + evals — agents in 50% of AI job posts, evals in 56%. When an agent beats a fixed chain; how you measure answer quality.
  • 7. Deploy + fine-tune concepts — APIs, Docker basics; LoRA: what it changes, when RAG wins instead. You have run the experiment.

What the roadmaps get right: AI engineers build on existing models — they do not train foundation models. Software fundamentals outrank ML theory. Your ladder is steps 1–3 (build now) on top of steps 5 and 7 (already lived).

Daily plan — 2-hour side block

  • 60 min — coding. OA track: one DSA pattern, solve → explain → test. Serves every loop on this page.
  • 30 min — one GenAI or system-design topic. Google first: RAG pieces, evals, one design question.
  • 30 min — one story out loud. Pick a Leadership Principle or Googleyness prompt, answer in 2 minutes, record yourself, listen once.

SI stays the main track. This block is the side quest — small, daily, compounding.
