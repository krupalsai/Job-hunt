Interview rehearsal

Do this after the course. You should be able to answer with your own verified examples, not memorize a script.

1. What problem does this project solve?

Answer: intended user → problem → useful feature → example outcome.

2. Walk me through one feature.

Answer: screen/action → request if one is made → server or data work if applicable → result → error case.

3. Where is that behavior implemented?

Open the exact page, script or route, then follow its calls. Do not guess file names or claim a route exists until you locate it.

4. How does data reach the app, and how fresh is it?

Separate page loading, API requests, database reads, and scheduled refreshes. Give measured timings only if you have measured them.

5. What did you personally build or fix?

Describe one real change: symptom → investigation → fix → verification → what you learned.

6. What would you improve next?

Name one concrete limitation, explain its impact, and describe how you would test the improvement.
